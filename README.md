## 🚀 Getting Started

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install the dependencies required by the notebooks.
4. Open the notebooks in VS Code or Jupyter.
5. Execute the cells in order.

Example setup:

```bash
python -m venv .venv
```

Activate on Windows:

```bash
.venv\Scripts\activate
```

Install the dependencies used by the notebooks:

```bash
python -m pip install "qiskit[visualization]" qiskit-aer qiskit-ibm-runtime numpy pylatexenc qc-grader
```

Some exercises require an IBM Quantum account and access to real quantum hardware. Hardware execution may involve queueing and is not required for ordinary local simulation.
